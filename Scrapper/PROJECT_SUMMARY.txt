🚀 QUICK START (5 MINUTES)
─────────────────────────────────────────────────────────────────────────────

1. Install dependencies:
   cd Scrapper
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r ../requirements.txt

2. Run tests:
   pytest

3. Start API server:
   uvicorn app.main:app --reload
   → Open: http://localhost:8000/docs (Swagger UI)

4. Scrape from CLI:
   python scripts/run_scraper.py \
     --source chiletrabajos \
     --query "practica informatica" \
     --max-pages 2

5. Query via API:
   curl "http://localhost:8000/offers?query=practica&location=Santiago"

📚 USAGE EXAMPLES
─────────────────────────────────────────────────────────────────────────────

API: Scrape and save to database
  curl -X POST http://localhost:8000/scrape \
    -H "Content-Type: application/json" \
    -d '{
      "source": "chiletrabajos",
      "query": "practica ingenieria",
      "location": "Santiago",
      "date_range": "last_month",
      "max_pages": 2
    }'

API: List offers with filters
  curl "http://localhost:8000/offers?query=python&location=Valparaiso"

CLI: Scrape without API
  python scripts/run_scraper.py \
    --source chiletrabajos \
    --query "practica data" \
    --location "Valparaiso" \
    --max-pages 3

Python: Programmatic usage
  from app.database import SessionLocal
  from app.services.scrape_service import ScrapeService
  
  db = SessionLocal()
  result = ScrapeService.scrape_and_save(db, "chiletrabajos", "practica")
  print(f"Found: {result['total_found']}, Saved: {result['new_offers_saved']}")
